# Streamlit Dashboard

Interactive dashboard for the Brazilian E-commerce Analytics project.

## How to run

From the project root:

```powershell
streamlit run app/streamlit_app.py
```

The dashboard uses:

```text
data/processed/orders_analytics.csv
```

If this file does not exist, run the notebook:

```text
notebooks/03_feature_engineering_and_dataset.ipynb
```
