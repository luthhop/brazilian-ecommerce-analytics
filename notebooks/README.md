# Notebooks

Esta pasta armazenará os notebooks de análise.

Planejamento inicial:

1. `01_data_understanding.ipynb`: entendimento das tabelas e qualidade dos dados.
2. `02_exploratory_analysis.ipynb`: análise exploratória inicial e visualizações.
3. `03_feature_engineering_and_dataset.ipynb`: criação da tabela analítica consolidada.
4. `04_sql_business_analysis.ipynb`: consultas SQL para responder perguntas de negócio.
5. `05_business_insights.ipynb`: síntese dos principais insights.
