# Dados

Os dados deste projeto vêm do dataset público da Olist no Kaggle:

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Como organizar os arquivos

Depois de baixar o dataset, extraia os arquivos `.csv` dentro da pasta:

```text
data/raw/
```

Os dados tratados gerados durante o projeto serão salvos em:

```text
data/processed/
```

## Observação

Os arquivos de dados não serão versionados no GitHub para manter o repositório leve. As pastas permanecem no projeto usando arquivos `.gitkeep`.
