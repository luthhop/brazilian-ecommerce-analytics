# Plano do Projeto

## 1. Definição do problema

Tema: análise de performance comercial, logística e satisfação em um e-commerce brasileiro.

Objetivo principal: transformar dados brutos de pedidos em insights de negócio que possam apoiar decisões sobre vendas, entrega e experiência do cliente.

## 2. Entregáveis finais

- Repositório GitHub organizado
- Notebook de análise exploratória
- Consultas SQL documentadas
- Base tratada para dashboard
- Dashboard em Power BI
- README com visão executiva do projeto
- Post para LinkedIn apresentando o projeto

## 3. Etapas

### Etapa 1: Preparação

- Criar estrutura de pastas
- Baixar dataset da Olist no Kaggle
- Salvar arquivos originais em `data/raw`
- Registrar fonte dos dados

### Etapa 2: Entendimento dos dados

- Listar arquivos disponíveis
- Entender chaves entre tabelas
- Verificar quantidade de linhas e colunas
- Identificar tipos de dados
- Criar dicionário inicial de dados

### Etapa 3: Limpeza e tratamento

- Tratar datas
- Verificar valores ausentes
- Verificar duplicidades
- Padronizar nomes de colunas, se necessário
- Criar tabelas tratadas em `data/processed`

### Etapa 4: Análise exploratória

- Evolução temporal de pedidos e receita
- Receita por categoria
- Pedidos por estado
- Análise de frete
- Análise de prazo de entrega
- Relação entre atraso e nota de avaliação

### Etapa 5: SQL

- Criar base SQLite
- Escrever consultas de negócio
- Documentar respostas e interpretações

### Etapa 6: Dashboard

- Definir KPIs principais
- Criar modelo de dados no Power BI
- Montar páginas do dashboard
- Validar consistência dos números

### Etapa 7: Comunicação

- Atualizar README final
- Criar resumo executivo
- Escrever aprendizados
- Preparar publicação para LinkedIn

## 4. KPIs candidatos

- Receita total
- Total de pedidos
- Ticket médio
- Frete médio
- Prazo médio de entrega
- Percentual de entregas atrasadas
- Nota média de avaliação
- Receita por categoria
- Receita por estado

## 5. Papel da IA no projeto

A IA apoia a estruturação, escrita de código, documentação, revisão e geração de ideias. O autor conduz o projeto, valida os resultados e decide quais análises entram no material final.
